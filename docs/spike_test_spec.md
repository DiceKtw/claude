# Spike 測試規格：pyJianYingDraft × 剪映國內版 10.9.0 最小閉環

> 本文件只定義**測試規格與執行步驟**，不含正式功能。
> 待確認後，才撰寫**一支拋棄式 spike 腳本**進行驗證。

---

## 0. 目的與範圍

**目的**：驗證 pyJianYingDraft 能否在 **Windows + 剪映國內版 10.9.0** 產生一個
**剪映可開啟、可人工修改**的最小草稿。

**明確排除（本階段不做）**：
- ❌ 不接 AI
- ❌ 不接 Whisper
- ❌ 不建立正式 exporter（不做抽象層、不做 EDL 對接）
- ✅ 只做**一次性 spike 驗證**，程式用完即可丟

| 步驟 | 動作 | 通過條件 |
|------|------|---------|

## 3. 關卡 1：最小草稿 spike

### 3.1 spike 腳本要做的事（規格，非最終程式）

**只做以下最小動作**，一支影片、一段時間軸：

1. 指向草稿根目錄：`DraftFolder("D:\\JianyingPro Drafts")`
2. 建立草稿：`create_draft("spike_test", 1920, 1080)`（名稱 + 解析度）
3. 新增一條**影片軌**
4. 用測試影片建立素材：`VideoMaterial(r"D:\footage\test.mp4")`
5. 建立一個影片片段，設定時間範圍（例：從 0s 起、長 5s）——
   使用 `trange(...)`，**單位為微秒**（`"5s"` = `5_000_000`）
6. 把片段加入影片軌
7. **透過 `DraftFolder` 存檔**（讓草稿同時產生 `draft_meta_info.json`，
   剪映才會在草稿列表看到它）——不要只 dump 單一 `draft_content.json`

> ⚠️ 上述 API 名稱（`DraftFolder` / `create_draft` / `VideoMaterial` /
> `VideoSegment` / `trange` / `add_segment` / `save`）依官方文件整理，
> **實際簽名以安裝版本為準**；spike 腳本會對照安裝版真實 API 再定案。

### 3.2 路線判定（關卡 1 的核心產出）

```
產生草稿 → 關閉剪映 → 開啟剪映 → 載入 spike_test 草稿

  能開、無「升級草稿/報錯/閃退」  → 【路線 A 成立】明文直開可行 ✅
  要求升級 / 打不開 / 亂碼        → 【走路線 B】
                                    用 jy-draftc 對草稿做 v2 回加密後再開
                                    （jy-draftc 已驗證涵蓋 10.9.0）
```

**本階段只要判定出走 A 還是 B，並讓草稿成功開啟即可。**

## 4. 執行步驟（Windows 上逐步照做）

1. 確認 `D:\JianyingPro Drafts` 為 10.9.0 實際草稿目錄（關卡 0-1）。
2. 建虛擬環境並 `pip install pyJianYingDraft`（關卡 0-2）。
3. 放好測試影片，記下絕對路徑（關卡 0-3）。
4. **關閉剪映**。
5. 執行 spike 腳本產生 `spike_test` 草稿。
6. 開啟剪映，查看草稿列表是否出現 `spike_test` 並可載入。
7. 依第 5 節逐項驗收；若載入失敗 → 走路線 B 後重試。
8. 把結果填入第 6 節記錄表，回報。

## 5. 成功標準（閉環驗收）

| # | 標準 | 通過條件 |
|---|------|---------|
| 1 | 剪映可以開啟草稿 | `spike_test` 出現在草稿列表且正常載入，無升級/報錯 |
| 2 | 可以看到一支影片 | 時間軸影片軌有該片段，**非離線紅片段**（素材路徑正確） |
| 3 | 可以在時間軸修改 | 能拖動片段、裁切、加字幕 → 確認草稿可編輯而非唯讀 |

三項全過 = **最小閉環成立**。

## 7. 風險與注意事項

| 項目 | 注意 |
|------|------|
| 草稿目錄含空白 | `D:\JianyingPro Drafts` 路徑有空白，字串需完整處理，不可截斷 |
| 素材路徑 | 一律 Windows 絕對路徑，否則變離線紅片段 |
| 寫草稿時機 | **寫入前先關閉剪映**，寫完再開 |
| API 版本差異 | 官方文件 API 名稱僅供規格；腳本以安裝版真實簽名為準 |
| 加密退路 | 路線 A 失敗才用 jy-draftc（v2，已驗證含 10.9.0），不預先加密 |
| 時間單位 | 剪映內部微秒；`"5s"` = `5_000_000`，換算錯不會報錯但片段全錯 |
